# 项目主页与研究成果发布 / Research Project Release

> **类别：原创工作流程模板** · 仅用于公开已获得作者授权的科研成果。

## 何时用

论文已经准备好对外发布，需要做项目主页、演示视频、可复现实验资料、README 或博客介绍。

## 输入

- 已公开或明确允许发布的论文、真实结果、作者信息和许可材料。
- 已核实的性能数字、代码及模型权利、视频演示、复现依赖。
- 对象：研究同行、复现使用者、社区贡献者。

## 工作流程

1. **首先列出可公开清单**：稿件、图表、视频、代码、权重、数据、作者署名、访问权限；未授权资料不得上传。
2. **Hero 传达一个能被验证的主张**：论文名称、简洁的研究问题和可靠证据入口；不要伪造宣传数字。
3. **按论证顺序放真实证据**：最重要的结果/演示 → 方法机制 → 定量对照 → 失败与局限 → 论文/代码/数据。
4. **保证可检索与可复现**：摘要、项目元信息、论文与仓库链接、依赖环境、license、版本和关键运行命令。
5. **适配人类和 Agent**：网页便于快速扫读；结构化文本可访问；大视频提供摘要和有意义的海报帧，不只把文本藏在图片里。
6. **真实发布验收**：桌面与移动端、链接、视频加载、版权说明、截图阅读、无障碍与最终页面。

## 输出

- 项目主页内容顺序和所需素材清单。
- 已核验的主张—证据链接；发布权限记录。
- README 与复现入口审查表。
- 未完成/不可公开项目清单，不把未发布成果伪装成已上线能力。

## 验收

- 项目主页上任何定量性能主张都可追溯，概念示意与真实演示明确标注。
- 不复制无授权的第三方网站或论文素材；设计参考只迁移原则。
- 可被普通读者和有网页访问能力的 Agent 发现关键信息。

**English:** Audit publishing rights, lead with a verifiable claim, present real results and demos, provide reproducible artifact links, and review desktop/mobile accessibility and attribution before release.
