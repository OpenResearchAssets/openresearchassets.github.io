# 文献检索与证据筛选 / Literature Triage

> **类别：原创科研工作流程** · 建议人工复核 · 非替代系统综述、无自动联网执行能力。

## 何时用

需要为新研究方向明确相关工作、寻找技术空缺，或判断“是否有人已经做过”。不要只凭单篇高引用论文得出领域结论。

## 输入

- 当前研究问题（一至两句话），目标场景与关键约束。
- 需要覆盖的时间范围、领域、会议/期刊或开放资源。
- 可以访问的论文检索工具；若工具不可用，明确列出仍需验证的检索项。

## 工作流程

1. **问题拆解**：把目标拆成研究对象、机制、评价指标、适用条件与边界；生成中英文同义词和术语别名。
2. **多路检索**：分别搜索奠基论文、最近进展、开源方法、负面结果和交叉领域；记录查询式与检索日期。
3. **按证据筛选**：检查论文原文与官方代码，区分明确证据、作者主张、我们的推断；不要使用二手摘要替代验证。
4. **构建对比矩阵**：每行一篇工作；列包括核心问题、方法、输入输出、训练/推理开销、评估设置、开源程度、已知局限和来源。
5. **识别空缺**：提出“什么任务在什么条件下仍做不好”的可验证假设，并主动找最接近的反例。
6. **决定下一步**：优先确定能够最快证伪/证实假设的小实验，而不是立刻启动重型 Benchmark。

## 输出

- 研究问题一段话；检索词、日期与覆盖边界。
- 相关工作矩阵（每项官方链接）。
- 三条以内可验证研究假设及各自最强反例。
- 证据不足清单与下一轮检索/实验建议。

## 验收

- 关键结论能回溯到论文具体章节/图表/仓库，而不是缺失出处的模型断言。
- 不把 arXiv 预印本写作已被会议录用，除非经官方确认。
- 未覆盖的年份或数据库必须披露；“尚未找到”不等于“没有人做过”。

**English:** Define the question and search coverage, expand queries, verify primary sources, compare methods in a traceable evidence table, actively seek counterexamples, and produce falsifiable gaps. This workflow is a reusable template, not an exhaustive search service.
