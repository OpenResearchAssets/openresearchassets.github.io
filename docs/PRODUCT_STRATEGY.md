# 公开产品策略 / Public Product Strategy

> 这是**可以公开的简要项目边界**，不是内部商业计划；更详细的竞品判断与尚未发表研究资料不能放在这个仓库。

## 项目价值

为科研人员提供精选、来源可靠的科研表达案例、可编辑设计资产和能够实际遵循的质量审核方法。**Quality first** 既要求审美，也要求科学保真、实际可用、可复用。

## 方法与工具优先

优先开发对用户立刻有用的能力：**具体诊断问题 → 给出可执行修订方法 → 保留科学事实 → 检查真实出版版面**。Benchmark / 数据集主要作为内部验证工具，不以收录规模和刷榜作为主要产物。尚未实现的自动诊断或改图服务不能列作当前功能。

## 已上线的最小开放产品

- 可搜索外部参考卡片；其图像版权归原权利人。
- 三张原创可编辑、明确标注的概念 SVG。
- 浏览器内五种研究对象的**人工勾选**检查清单和 Markdown 修改报告。
- 可供支持文件查看的 Agent 参照执行的质量检查 Skill（没有独立的性能验证）。
- 中文默认、英文完整可切换的静态网站，无需我们的服务器推理。

## 后续决策原则

先通过真实用户案例验证免费能力是否改善科研表达，再考虑一次性原创模板、授权明确的修图服务或更完整的本地编辑工作流。不会因为出现 Star 就推断有付费需求，也不会将开放社区贡献直接转为收费商品。只有有明确需求和可控成本才会考虑托管 SaaS 或专用模型。

## 禁止的误导性宣称

不得声称网站已具备自动 AI 审图、用户 PDF 上传、自动改图、专家级评分、订阅收费、模型训练成效或用户群体指标，除非**该功能已经实现且通过相应验证**。

**English summary:** We prioritize useful quality-improving methods over benchmarking for its own sake. The public product currently offers curated source links, three editable concept SVGs, a manual self-review checklist, and an unvalidated Agent skill. Later options are not existing features.
