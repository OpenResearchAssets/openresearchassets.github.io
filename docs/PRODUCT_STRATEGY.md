# 公开产品定位与真实功能

OpenResearchAssets 是**科研全过程可发现、可理解、可复用的资产库**，服务人类和有文件/网页读取工具的 AI。首批高质量积累集中在 AI / CV / Robotics 的科研视觉表达与工作流，但分类架构不限于论文绘图。

## 长期目标：从研究资源收藏到任务级复用

**北极星目标：研究者只需把网站地址交给具备网页读取能力的 AI，并提供当前任务与必要权限，AI 就能自主定位与复用最相关的科研经验和工具，减少重复搜索、额外提示、人工介入、试错和 Token 消耗。**

覆盖科研完整生命周期：研究选题 → 文献调研 → 方法设计 → 实验实施 → 评估分析 → 论文写作 → 投稿展示 → 开源传播。资产既可以是论文视觉案例、优质项目主页，也可以是方法论、实验排错案例、工作流、工具、Skill、模板和能够直接编辑的源文件。不能让当前视觉素材的优势限制长期用途。

任何资产的目标是从「被看见」升级为「被发现 → 被理解 → 被选择 → 被真正使用 → 被验证」。单条记录要描述适用条件、可迁移原则、操作步骤或输入输出（适用时）、使用限制、官方来源和版权边界，避免成为只有链接或泛泛赞美的收藏夹。

**成功标准**：让同一类科研任务的检索命中率与最终结果质量更好，同时减少完成时间、Agent 不必要的上下文/Token 消耗与人工补充说明次数。应进行真实任务对照，严格区分「静态网站已经具备机器可读入口」与「有工具权限的 AI 在任务中确实取得收益」；后者尚未验证。

## 现在实际可用的功能

- [科研资产目录](../catalog/index.json)：22 条独立建档资源，含 Teaser、项目主页、原创 SVG、工具目录、四份原创科研工作流与质量审核 Skill；双语用途、来源和边界。
- [任务检索](../index.html#references)：当前支持本地文字匹配与阶段、领域、资产类型组合筛选，非向量语义搜索。
- [独立详情](../asset.html?id=supermimic-site)：使用条件、可学习点、风险、来源和相关资产。
- [AI 导航入口](../for-agents/) 和 [llms.txt](../llms.txt)：可公开抓取的指南与 JSON，不是自动执行科研任务的服务。
- 五份原创可编辑 SVG **概念**示意、浏览器人工自查清单以及供 AI 参考的质量检查 Skill。

## 核心原则

**经验必须可复用，科学事实必须保真，来源必须可追溯。** 专门研究质量提升的方法与 Skill，而不是仅建设大型 Benchmark；Benchmark/小规模用户研究用于独立评价实际收益。

资产类型可以扩展到研究选题、文献调研、方法设计、实验管理、评估、论文写作、展示和科研传播，但当前不存在的资产类别不宣传为已经完整覆盖。

## 未提供的能力

目前**没有**自动模型审图、上传 PDF 的云端科研助手、远程工作流执行、自动向量语义检索、收费产品或经过独立专家验证的质量模型。未来项目按实际需求与能力再决定。

**English:** A Chinese-first, research-lifecycle asset catalog with English metadata and human/agent-readable entry points. Current capabilities are static catalog search, original editable examples and a manual quality checklist. No hosted autonomous agent or automated image judge is deployed.
