# OpenResearchAssets · 科研设计精品资产库

**Craft better research.** 让科学表达既准确、清晰，也足够精致。

这是一个面向全球研究者的**高质量优先**项目。我们不追求素材最多，而是逐步积累值得学习的视觉作品、原创可编辑资产，以及能够指出配图、配表和论文叙事问题的质量检查方法。

英文 [README](README.md) 是当前项目完整使用说明。第一版英文网页便于全球研究者使用；中文说明保留以方便维护和评审。

## 首版已包含

- `index.html`：静态产品主页、精选外部参考入口与搜索筛选。
- `quality.html`：本地浏览器质量自检工具，覆盖 Teaser、方法图、实验图、表格和整篇论文；可生成 Markdown 修改清单。
- `skills/quality-critic/SKILL.md`：面向支持多模态输入的 Agent 的质量审核 Skill。它提供具体审核流程，**尚未经过独立质量基准验证**。
- `assets/templates/`：三张原创、逐元素可编辑 SVG 概念模板，不包含真实实验指标。
- `docs/QUALITY_STANDARD.md`：科学忠实性、信息表达、美学、投稿排版及全文一致性标准。
- `docs/ASSET_POLICY.md`：第三方论文图仅保留来源链接；原创素材单独授权，不擅自公开私人研究数据。
- `docs/PRODUCT_STRATEGY.md`：先开源验证需求，暂不租 GPU、做高成本 SaaS 或训练专有模型。

## 运行方式

直接打开 `index.html` 和 `quality.html`；也可以在仓库根目录运行：

```bash
python3 -m http.server 8000
python3 tests/check_project.py
```

不需要 npm、服务器、账号、数据库和推理额度。以后可以部署到 Cloudflare Pages 等静态托管平台。移动端与 Chromium 实际交互需在可用浏览器环境中复核。

## 核心原则

1. **科学真实性高于审美**。不得为了漂亮修改数值、夸大实验结论。
2. **少而精**。每条参考都要说明为什么值得学习，不能只附一个网址。
3. **真正可编辑**。SVG 中每个重要文字和形状应能独立编辑，不能将截图伪装成矢量图。
4. **按最终论文版面检查**。画布上好看不等于投稿 PDF 中清晰。
5. **尊重版权和隐私**。第三方原图不擅自转载；用户未公开稿件和数据不进入公共仓库。
6. **先建立价值，再探索收费**。社区开放内容保持开放；付费部分必须有独立授权和明确的增量价值。
