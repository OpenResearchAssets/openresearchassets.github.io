OPEN CONTRIBUTIONS / 开放投稿

分享值得被发现的科研资产。

好看的论文图、优秀项目主页、可编辑素材，或真正有用的 Skills / Workflows，都值得分享。任何 GitHub 用户都可以投稿；进入 Community 无需等待精选审核。

01 / SUBMIT

从 GitHub 提交，一步进入社区。

填写作品名称、官方链接和推荐理由即可。公开 Issue 自动记录你的 GitHub 用户名与投稿时间，也可附上你有权分享的原创文件。

提交科研资产 ↗

无需仓库写权限 · 公开投稿后即可获得点赞和评论 · 入选 Curated 需单独审核

02 / A GOOD SUBMISSION

只需要把三件事讲清楚

01

原始来源

链接原作者主页、仓库或论文，并区分作者与投稿者。

02

推荐理由

指出具体可借鉴的视觉表达、任务价值或实际使用经验。

03

版权与事实

第三方作品优先链接原站，不上传未经许可的图片或未发表材料。
